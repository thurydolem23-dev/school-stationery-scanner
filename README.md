# School Stationery Inventory Scanner

A custom web-based inventory management interface developed to support school stationery tracking, stock transactions, and organised inventory records.

## Project Overview

This project demonstrates the development of a user-friendly inventory interface for managing school stationery and supplies.

The goal is to simplify inventory recording, improve stock visibility, and support efficient administrative workflows.

## Key Features

- User-friendly inventory interface
- Item information and category management
- Stock-in and stock-out recording
- Storage location tracking
- Staff information recording
- Mobile-friendly interface
- Structured inventory data management

## Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages

The broader inventory workflow also uses Google Sheets and Google Apps Script for inventory records and automation.

## Project Highlights

- Developed a custom inventory interface for school stationery management.
- Designed structured workflows for recording inventory transactions.
- Implemented inventory tracking processes using Google Sheets and Google Apps Script.
- Created a mobile-friendly interface to support stockroom operations.

## Project Purpose

This project demonstrates practical skills in:

- Inventory Management
- Administrative Process Improvement
- Data Organisation
- Workflow Automation
- Web Interface Development
- Operational Reporting
